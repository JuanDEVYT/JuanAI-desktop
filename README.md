# JuanAI — Instalador de escritorio

Este repo solo contiene los **binarios ya compilados** del instalador de Windows de JuanAI
(ver [Releases](https://github.com/JuanDEVYT/JuanAI-desktop/releases/latest)). No hay código
fuente aquí: la app en sí es un repo privado aparte. Este repo lo llena automáticamente el
workflow de compilación cada vez que se publica una nueva versión.
